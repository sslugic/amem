# Plugin marketplaces: submission checklist

The amem plugin pack is generated by `scripts/sync-plugins.mjs` (run `npm run plugins`; CI fails if it drifts). Installing straight from this repo already works:

- Claude Code: `/plugin marketplace add sslugic/amem`, then `/plugin install amem@amem`
- Codex: `codex plugin marketplace add sslugic/amem`, then `/plugins`
- Gemini CLI: `gemini extensions install https://github.com/sslugic/amem`
- Claude Desktop: `amem.mcpb`, attached to every GitHub release by `release.yml`

Listing in each vendor's catalog makes amem discoverable without the command. Each needs the owner's account, so submit these by hand:

| Catalog | Where | What to submit | Notes |
| --- | --- | --- | --- |
| **Cursor Marketplace** | cursor.com/marketplace/publish | Repo `https://github.com/sslugic/amem`, plugin path `plugins/amem` | Reviewed by hand. The plugin brings the MCP server, `rules/amem.mdc`, skills and Cursor hooks. Test locally first: `ln -s "$PWD/plugins/amem" ~/.cursor/plugins/local/amem`, then reload the window. |
| **Claude plugin directory** | claude.com/docs/plugins/submit | Repo and path `plugins/amem` | Run `claude plugin validate plugins/amem` first; it passes with `network.hosts` declared. The directory also runs a safety scan. |
| **Codex / ChatGPT plugin directory** | developers.openai.com/plugins/deploy/submission | `plugins/amem` (Agent Plugins `plugin.json` + `mcp.json`) | Local stdio MCP servers in the public directory are limited to approved partners, and plugins with hooks aren't eligible. The marketplace route above works regardless. |
| **Gemini CLI extensions gallery** | geminicli.com/extensions | `https://github.com/sslugic/amem` | Listed from public GitHub repos that have a root `gemini-extension.json`. |
| **MCP Registry** | already published by `release.yml` (`server.json`) | — | Nothing to do. |

Keep the descriptions to the tagline: *amem — agent memory, anchored to your code.*
